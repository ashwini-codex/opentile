# Golden example: R=C=2, K=3 (hand-checked, simulated)

A = [[1, 2, 3], [4, 5, 6]]  (2x3), B = [[1, 0], [0, 1], [1, 1]]  (3x2). C = A x B = [[4, 5], [10, 11]].

Feed (unskewed vector at feed cycle k): a_vec(k) = column k of A, b_vec(k) = row k of B.
Product A[i][k]*B[k][j] lands at PE(i,j) in array cycle t = i+j+k.

| t | PE(0,0) acc | PE(0,1) acc | PE(1,0) acc | PE(1,1) acc |
|---|---|---|---|---|
| 0 | 1 | 0 | 0 | 0 |
| 1 | 1 | 0 | 4 | 0 |
| 2 | 4 | 2 | 4 | 0 |
| 3 | 4 | 5 | 10 | 5 |
| 4 | 4 | 5 | 10 | 11 |

Each row shows accumulator values **after** the clock edge that ends cycle t. The last change is in cycle t = 4 = K+R+C-3, so compute lasts K+R+C-2 = 5 cycles. After t=4 nothing changes.

Reproduce: `python3 scripts/golden_check.py` (checks the formula for R,C in 1..5, K in 1..8 against a plain triple loop).
